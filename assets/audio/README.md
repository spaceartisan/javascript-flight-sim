# AERONAUT audio sample bank

**Source:** GeneralUser GS v2.0.3 by S. Christian Collins — `GeneralUser-GS.sf2` from the user's `DEV_TOOLS/audio.zip`.

**Rendering:** `tools/render-generaluser.py` uses FluidSynth's actual SF2 preset samples; layered recordings are filtered, crossfaded, level-matched and compressed as Ogg Vorbis. Files were generated offline at 44,100 Hz stereo. The game never downloads or embeds the 31 MB SF2 itself.

|---|---|---|
